# 山野精灵.晴雨表 · 定制与二次分发指南

本文供 AI 在帮用户做 B 端定制、二次分发或升级时参考。

## 一、SCENES 场景阈值定制（B 端核心）

在应用 HTML 的脚本内搜索 `SCENES`，结构如下：

```javascript
var SCENES={
 '场景名':{rules:[
   {max:0.1, level:'ok',   txt:'无降水，正常安排'},
   {max:10,  level:'watch',txt:'…'},
   {max:9999,level:'stop', txt:'…'}
 ]},
 …
};
var LVTXT={ok:'可作业',watch:'有条件',stop:'建议停',none:'无数据'};
```

规则：
1. `rules` 从严到宽排列，判定取第一条 `mm < max` 命中的规则；最后一条 `max` 写 `9999` 兜底。
2. `level` 只允许 `ok / watch / stop`（界面配色与导出图自动跟随，无需改样式）。
3. 阈值必须来自客户自己的作业规程/施工规范/农事手册——让客户把数字给你，工具就成了"客户自己的系统"。
4. 改前备份：复制一份 `山野精灵.晴雨表.html.bak.YYYYMMDD`；改完刷新页面，切换 tab 4 的场景下拉即可看到新场景。
5. 增删场景只动 `SCENES`，界面下拉、导出对话框、画布渲染自动同步。

内置四套默认阈值（可作参考起点）：

| 场景 | 关键阈值行为 |
|---|---|
| 通用参考 | <10mm 不影响户外；25-50mm 停露天作业 |
| 建筑施工 | ≥1mm 即覆盖浇筑/停饰面防水；≥10mm 停混凝土浇筑 |
| 农业种植 | 0.1-10mm 停喷药；≥25mm 防渍涝清沟 |
| 户外物流 | <10mm 装卸照常；≥25mm 山区线路防塌方；≥50mm 延迟发车 |

## 二、月度损失台账

场景决策视图顶部统计"本月建议停 X 个半天 / 有条件 X 个半天"（按实测值、含当天），用途：
- 工期索赔 / 监理对账的气象依据；
- 农业保险、工程险理赔佐证（配合页脚数据来源声明与官方校订值）；
- 月度复盘：把损失折算成金额，作为订阅续费的谈判锚点。

## 三、品牌与文件名

- 品牌名唯一常量：脚本内 `APP_NAME`（当前 `山野精灵.晴雨表`）。改名只动这一行 + 页面 `<title>` 静态行，其余标题/文件名/分享文案全部引用 `APP_NAME`。
- 文件名规则：`fileName()` = `APP_NAME + '_' + 地名`（如 `山野精灵.晴雨表_重庆南岸区`），另存为、导出 PNG/PDF、打印窗口标题自动跟随。
- 二次分发（给客户/朋友）：直接复制 HTML 文件即可；接收方数据独立存在其浏览器 localStorage（键 `cq_nanan_rain_v1`），互不影响。

## 四、授权体系（作者侧）

- 客户端：ECDSA P-256 验签，公钥内嵌 HTML；授权码格式 `QY-载荷-签名`（Crockford Base32），绑定到期日、档位（Y 年费 / M 月费）与机器码（可选）。
- 机器码：订阅对话框可见"本机码"（环境指纹 FNV-1a，同设备同浏览器稳定）。
- 签发工具与私钥**只保留在作者本地**，不随应用分发、不进任何公开包；私钥泄露=授权体系作废。
- 定价参考：个人月费 5 元 / 年费 12 元；B 端定制单（施工项目部 1000-3000 元/年、农场 500-1500 元/年）另议，定制内容=专属 SCENES 阈值 + 损失台账口径。

## 五、升级与版本纪律

1. 权威版本永远只有一份（作者工作区），改完再分发，不要多处分头改。
2. 任何修改前备份 `.bak.YYYYMMDD`；改完做最小验证：浏览器打开 → 切四个 tab → 导出一张 PNG。
3. 数据兼容：`years/official/locks` 结构向后兼容；新增字段用可选字段，避免老数据导入报错。
