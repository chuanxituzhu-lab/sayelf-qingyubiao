# 运行契约

## 输入

- `location`：城市、区县或浏览器定位结果。
- `dateRange`：年份、月份或起止日期。
- `scene`：可选行业或作业场景。
- `action`：生成、解读、导出或分享。

## 输出

1. 先给出数据范围和数据来源状态。
2. 给出晴雨表结果或引导用户打开随包 H5。
3. 需要作业判断时，给出阈值依据和不确定性。
4. 分享时只生成面向朋友的自然说明，不加入外部联系方式、广告或站外水印。
5. 奖励只有在在线服务返回实际入账结果后才能说“已到账”；离线时说“分享已完成，奖励服务未连接”。

## 禁止行为

- 不编造实时天气、降水量或奖励到账结果。
- 不把点击、转发或安装本身当作有效奖励事件。
- 不推断用户身份，不向公共平台写入匿名账本。
- 不扩展农历为黄历、宜忌、命理或其他复杂内容。
