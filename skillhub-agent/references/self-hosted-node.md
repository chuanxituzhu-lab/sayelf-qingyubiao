# 自托管奖励服务（可选）

SkillHub 技能包可以离线使用晴雨表 H5。需要自动兑现邀请奖励时，在完整项目目录启动 Node 服务：

```bash
node server/server.cjs
```

服务使用 Node 内置模块，不需要安装依赖。可以通过 `PORT`、`HOST`、`PUBLIC_URL` 和 `DATA_DIR` 配置监听地址、公开地址与私有账本目录。`DATA_DIR` 应放在本机私有目录，不要提交到 GitHub、SkillHub 或其他公共平台。

奖励只在服务端收到“新用户首次成功同步天气并生成晴雨表”事件时结算：

| 角色 | 奖励 |
| --- | ---: |
| 新用户 | 7 分，即 7 天 Pro |
| 直接邀请者 | 7 分，即 7 天 Pro |
| 直接邀请者的上游 | 3 分，即 3 天 Pro |

只追溯一层上游，不计算第三级。每个账号按北京时间自然月最多入账 30 天；同一新用户的重复完成事件不会重复发放。累计 100 位有效直接邀请用户后，直接邀请者获得永久 Pro。

奖励服务不读取 H5 的本地天气记录，也不需要手机号、外部账号或广告链接。
